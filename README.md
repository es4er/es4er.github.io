# es4er 的个人主页

这里是 [es4er.github.io](https://es4er.github.io/) 的网站源代码仓库。

这不是一个独立的开源项目或作品集项目；它仅用于维护和发布我的个人主页。GitHub Pages 会从本仓库的 `main` 分支自动构建网站，因此请不要删除或随意重命名本仓库。

## 访问

- 个人主页：[https://es4er.github.io/](https://es4er.github.io/)
- GitHub 主页：[https://github.com/es4er](https://github.com/es4er)

## 更新主页内容

日常内容主要在以下位置维护：

- `_config.yml`：网站标题、简介、联系方式和社交链接
- `_pages/about-me.md`：个人介绍及页面主体内容
- `_pages/about/`：新闻、教育经历、荣誉等分区内容
- `images/`：头像和页面图片

提交并推送到 `main` 分支后，GitHub Pages 会自动重新部署，通常需要几分钟生效。
